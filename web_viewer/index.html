            Plantillas de estilo
            Ayuda de configuración de Plantillas

            Una plantilla define reglas de normalización y de estilo aplicables a un documento. Campos:

            • name: Nombre visible de la plantilla.
            • style_name: Etiqueta del estilo (ej. "Chicago 17").
            • language: Código ISO del idioma (es, en...).
            • scope: Ámbito de aplicación (project | global).
            • rules: Objeto JSON con claves de comportamiento.
            • meta: Datos extra (author, version, notes...).

            Claves soportadas dentro de rules (use true/false o valores indicados):

            • expand_first_occurrence: Expande la primera ocurrencia de cada abreviatura.
            • abbreviations.mode: "expand_all" | "first_only" | "no_expand".
            • punctuation_normalization: Normaliza espacios antes/después de signos.
            • spacing_cleanup: Limpia espacios duplicados y tabs.
            • title_case_headings: Convierte encabezados a Title Case.
            • italics_foreign_words: Aplica cursiva a palabras en otro idioma.
            • number_format: "group" (1.234) | "plain" (1234).
            • date_format: Formato fecha (ej. "YYYY-MM-DD", "DD/MM/YYYY").
            • trim_whitespace: Recorta espacios al inicio/fin.
            • collapse_multiple_spaces: Reemplaza secuencias de espacios por uno.
            • replace_patterns: Lista de objetos { find: "regex", replace: "texto" }.
            • glossary_auto_expand: Intenta expansión automática según glosarios.
            • highlight_new_terms: Marca términos añadidos recientemente.
            • track_changes: Genera diff para auditoría de cambios.

            Cualquier clave desconocida será ignorada hasta que se implemente soporte. Mantenga el JSON válido.

            Presets rápidos

            Pulse "Usar" para cargar el ejemplo en el campo de reglas:

            Mínimo
            {
  "expand_first_occurrence": true,
  "trim_whitespace": true
}
            Completo
            {
  "expand_first_occurrence": true,
  "abbreviations.mode": "first_only",
  "punctuation_normalization": true,
  "spacing_cleanup": true,
  "trim_whitespace": true,
  "collapse_multiple_spaces": true,
  "number_format": "group",
  "date_format": "DD/MM/YYYY",
  "replace_patterns": [
    {"find": "\\bSra\\.", "replace": "Señora"},
    {"find": "\\bSr\\.", "replace": "Señor"}
  ],
  "glossary_auto_expand": true,
  "track_changes": true
}
            Avanzado
            {
  "expand_first_occurrence": true,
  "abbreviations.mode": "expand_all",
  "punctuation_normalization": true,
  "spacing_cleanup": true,
  "trim_whitespace": true,
  "collapse_multiple_spaces": true,
  "number_format": "plain",
  "date_format": "YYYY-MM-DD",
  "replace_patterns": [
    {"find": "\\betc\\.", "replace": "etcétera"},
    {"find": "\\baprox\\.", "replace": "aproximadamente"},
    {"find": "\\bNº", "replace": "Número"}
  ],
  "glossary_auto_expand": true,
  "highlight_new_terms": true,
  "track_changes": true,
  "italics_foreign_words": true,
  "title_case_headings": true
}
            Puede editar el resultado tras insertarlo. Asegúrese de mantener sintaxis JSON.
